# Synthetic Structural Response Dataset

This dataset contains synchronized structural vibration and optical displacement time-series generated by the `simulation` module.

> [!NOTE]
> All parameters and signals represent synthetic prototype configurations for developing signal processing algorithms and machine learning classification pipelines. They do not represent certified civil infrastructure or real-world bridge safety thresholds.

## Dataset Structure

```
dataset/
├── raw/
│   ├── normal_event_001.csv
│   ├── warning_event_001.csv
│   ├── critical_event_001.csv
│   └── ...
└── README.md
```

## Signal Synchronization & CSV Schema

Each event is sampled at a common sampling rate (default $100\text{ Hz}$, $10.0\text{ s}$ duration, $1000$ rows) and saved as a CSV file with the following columns:

| Column Name | Data Type | Units | Description |
|---|---|---|---|
| `timestamp` | Float | seconds ($\text{s}$) | Uniform time vector starting at $0.0\text{ s}$ with $\Delta t = 0.01\text{ s}$. |
| `true_displacement` | Float | millimeters ($\text{mm}$) | Ground-truth primary structural displacement (damped oscillation + ambient drift). |
| `vibration` | Float | $\text{m/s}^2$ | Measured structural vibration / acceleration (dynamic response + sensor noise). |
| `optical_x` | Float | millimeters ($\text{mm}$) | Optical camera measured displacement along primary axis (with jitter and quantization). |
| `optical_y` | Float | millimeters ($\text{mm}$) | Optical camera measured transverse displacement. |
| `optical_rotation` | Float | degrees ($^\circ$) | Optical camera measured structural angular deflection. |
| `scenario` | String | categorical | Structural health scenario (`NORMAL`, `WARNING`, `CRITICAL`). |

## Scenarios Overview

1. **NORMAL**:
   - Healthy structure under normal ambient service and minor dynamic excitation.
   - Natural frequency $f_n = 5.0\text{ Hz}$, damping ratio $\zeta = 0.06$, displacement amplitude $\approx 0.6\text{ mm}$.
   - Fast transient attenuation, stable baseline.

2. **WARNING**:
   - Developing stiffness loss and reduced damping.
   - Natural frequency $f_n = 4.3\text{ Hz}$ ($-14\%$ frequency shift), damping ratio $\zeta = 0.035$, displacement amplitude $\approx 1.8\text{ mm}$.
   - Noticeably prolonged transient ringing after impact.

3. **CRITICAL**:
   - Significant structural degradation / stiffness degradation.
   - Natural frequency $f_n = 3.4\text{ Hz}$ ($-32\%$ frequency shift), damping ratio $\zeta = 0.012$, displacement amplitude $\approx 4.2\text{ mm}$.
   - Strong impact shock transient with persistent, lingering oscillations.

## Machine Learning Tabular Feature Dataset (`dataset/processed/`)

Step 3 provides parameterized tabular datasets consisting of engineered vibration and optical features extracted per independent event.

```
dataset/
├── raw/                         # Raw time-series event CSVs
└── processed/                   # Processed ML tabular datasets
    ├── all_features.csv         # Full 3000-event tabular dataset
    ├── train.csv                # 70% stratified training set (2100 events)
    ├── validation.csv           # 15% stratified validation set (450 events)
    ├── test.csv                 # 15% stratified holdout test set (450 events)
    ├── baseline_normal.csv      # Statistical baseline derived exclusively from NORMAL train events
    └── dataset_metadata.json    # Complete dataset provenance and generation metadata
```

### Controlled Parameter Variation
To prevent artificial class separation and model overfitting, each scenario is synthesized with continuous physical parameter ranges:
- **NORMAL**: $f_n \in [4.65, 5.35]\text{ Hz}$, $A \in [0.35, 0.95]\text{ mm}$, $\zeta \in [0.045, 0.075]$, impact $\in [0.5, 1.8]\times$.
- **WARNING**: $f_n \in [3.95, 4.75]\text{ Hz}$, $A \in [1.0, 2.7]\text{ mm}$, $\zeta \in [0.022, 0.048]$, impact $\in [1.6, 3.8]\times$.
- **CRITICAL**: $f_n \in [3.05, 4.05]\text{ Hz}$, $A \in [2.8, 5.8]\text{ mm}$, $\zeta \in [0.007, 0.022]$, impact $\in [3.8, 7.2]\times$.

Physical boundaries intentionally overlap between adjacent classes (e.g. natural frequency overlap in $[4.65, 4.75]\text{ Hz}$ between NORMAL and WARNING; strong NORMAL impacts overlapping with mild WARNING vibrations).

### Leakage Prevention & Baseline
- **Zero Event ID Overlap**: Stratified splitting partitions events so that an `event_id` belongs to strictly one split.
- **Strict Target & Metadata Exclusion**: Model input features comprise exclusively the 29 measurable engineering features; `scenario` is retained only as target $y$, and hidden simulation parameters are segregated into audit metadata.
- **NORMAL-Only Baseline**: `baseline_normal.csv` is computed strictly on NORMAL training events, providing $\mu, \sigma, \text{median}, \text{IQR}$ for normalized deviation scoring.
